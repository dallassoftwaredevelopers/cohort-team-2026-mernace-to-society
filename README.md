### Our project entails building an app that enables a property management company to more easily and more efficiently track and pay hundreds of bills across hundreds of properties.

## Running locally

### Backend

1. `cd backend/`
2. `npm install`
3. `copy .env.example into a .env file`
4. `npm run dev`
5. Verify: `GET http://localhost:3000/api/v1/health` returns `{ status: "ok" }`

### Frontend

1. `cd backend/`
2. `npm install`
3. `npm run dev`
4. open in browser Local: http://localhost:[specified port number]/
